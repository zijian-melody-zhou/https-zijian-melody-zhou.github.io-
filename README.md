# Zijian Zhou — Portfolio (GitHub Pages)

Free static portfolio site. No build step: plain HTML/CSS files.

- GitHub account: https://github.com/zijian-melody-zhou
- Repository to create: `zijian-melody-zhou.github.io` (must be public, exact name)
- Live site after publishing: https://zijian-melody-zhou.github.io/

## Publish on GitHub Pages
1. Log in to GitHub as zijian-melody-zhou.
2. Create a new public repository named exactly `zijian-melody-zhou.github.io`. Do not add a README/gitignore in GitHub (this folder already has the files).
3. In the new repository, use "uploading an existing file" and upload all files from this folder (index.html, social-media.html, game-design.html, cosplay.html, art.html, styles.css, README.md). `index.html` must sit at the repository root, not inside a subfolder.
4. In the repository: Settings -> Pages -> Source: `Deploy from a branch`, branch `main`, folder `/ (root)`. Save.
5. After a minute or two, open https://zijian-melody-zhou.github.io/ — anyone with the link can view it, no login, no cost.
6. To update later: edit the file in the repository (or upload a replacement) and commit — the site updates automatically.

## Before sharing the link
- Replace every `[ Add ... ]` placeholder with a real link, image or text.
- Social media page rule: link only to public posts, credit account owners, keep confidential work text-only.
- Images: put image files in `assets/`, then replace a placeholder thumb with `<img src="assets/FILE.jpg" alt="...">` inside the thumb div.
